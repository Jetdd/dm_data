二、DM Python SDK 安装与参数说明
1. SDK 简介
•
本SDK 的Python 包名为dm_quant_api_client，用于调用需要SM4 加密的量化
API 接口。
•
SDK 当前具备以下能力：
￮
自动完成请求报文的SM4 加密和响应解密
￮
统一封装HTTP 请求头、超时、证书校验等通用逻辑
￮
支持将接口返回结果默认转换为pandas.DataFrame
￮
支持请求参数和响应字段在驼峰命名与下划线命名之间自动转换

•
运行环境要求：
￮
Python 3.8 及以上
•
依赖包：
￮
requests>=2.25.0

pandas>=1.0.0
￮

6. 参数风格说明
SDK 支持对请求和响应字段名进行统一转换。
6.1 推荐使用方式
如果客户希望在Python 代码中统一使用下划线命名，建议开启pythonic=True：
Python
client = DMQuantApiClient(
app_key="YOUR_APP_KEY",
sm4_key="YOUR_SM4_KEY",
pythonic=True
)


--- Page 8 ---
开启后实际效果为：
•
请求参数中的python 风格(snake_case) 字段会自动转换为接口常用的驼峰风格
(camelCase)
•
返回结果中的驼峰风格(camelCase) 字段会自动转换为python 风格(snake_case)
如果客户侧代码本身就是按接口文档中的驼峰字段编写，可不使用pythonic 参数，此
时请求字段和返回字段都不会被自动修改。
Python
client = DMQuantApiClient(
app_key="YOUR_APP_KEY",
sm4_key="YOUR_SM4_KEY",
)
7. 总结说明
成功配置使用DM-PythonAPI，可总结为以下三步：
•
Step1：获取DM 最新版的client、app_key 和sm4_key、最新版用户手册（这
些信息可联系您的DM 客户经理获取）。
•
Step2：按照安装指引进行client 安装和key 的配置；
•
Step3：按照DM 函数的path 以及入参条件配置，即可成功调用该函数对应的数
据内容。

四、常见问题与注意事项
1. 初始化时报`app_key is required`
原因：
•
未显式传入app_key
•
也未设置环境变量INNO_APP_KEY
处理建议：
•
检查初始化代码是否传入了app_key
•
或确认运行环境中已设置INNO_APP_KEY
2. 初始化时报`sm4_key is required`
原因：
•
未显式传入sm4_key
•
也未设置环境变量INNO_SM4_KEY
处理建议：
•
检查初始化代码是否传入了sm4_key
•
或确认运行环境中已设置INNO_SM4_KEY
3. 请求返回HTTP 非200
SDK 会抛出HttpStatusError。


--- Page 61 ---
处理建议：
•
检查api_path 是否正确
•
检查网络连通性、网关权限和证书配置
4. 返回结果无法解密或不是合法JSON
SDK 可能抛出：
•
CryptoError
•
ResponseDecodeError
处理建议：
•
确认sm4_key 是否正确
•
确认服务端返回是否为约定的加密响应格式
•
确认接口是否已接入正确的网关和环境
5. 返回`DataFrame` 转换失败
当return_type="dataframe" 时，SDK 会尝试把返回结果转换为pandas.DataFrame。
如果接口返回结构不适合表格化处理，可能会报错。
处理建议：
•
确认接口返回是否为列表、data/columns 结构或普通字典
6. 返回“无订阅套餐”
该场景表示您暂无函数调用权限。
处理建议：
•
可联系客户经理
7. 返回“额度已耗尽”/”限流“等提示
该场景表示您的流量已达上限。
处理建议：


--- Page 62 ---
•
可根据field_names 字段筛选业务需要的字段出参
